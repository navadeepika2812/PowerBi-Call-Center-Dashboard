# 📞 Call Center Dashboard – Power BI Project

Welcome to the **Call Center Dashboard** project!  
This Power BI dashboard provides comprehensive insights into call center operations, helping managers and decision-makers monitor performance, analyze trends, and enhance customer experience.

---

## 📊 Project Overview

The goal of this project is to visualize call center data in an interactive and insightful way using **Power BI**. It includes both a **summary (Home)** and a **detailed (Grid)** view to analyze key call metrics, customer interactions, and operational performance.

---

## 🔍 Key Features

### 🏠 Home Dashboard
- **Total Calls, Call Duration (in minutes & hours), Average Duration, Response Time**
- Visual breakdowns of:
  - 📅 Total Calls by Day
  - ❓ Calls by Reason (Billing, Service Outage, etc.)
  - 👤 Total Call Time by Customer Name
  - 🌐 Total Calls by Channel (Call Center, Chatbot, Email, Web)
  - 😊 Calls by Sentiment (Negative to Very Positive)
  - 🏙️ Total Calls by Call Center City

### 📋 Grid Dashboard
- Row-wise breakdown of:
  - Customer Name
  - Timestamp
  - Channel
  - Reason
  - SLA Status
  - Response Time
  - Call Duration (in minutes)
- Fully **filterable by Date, Channel, and City**

---

## 💡 Insights Enabled
- Identify top issues (e.g., billing-related queries)
- Monitor SLA adherence and response times
- Detect peak call days and times
- Understand customer sentiment trends
- Improve workload distribution across cities/channels

---

## 🛠️ Tools Used
- **Power BI**
- Power Query for data transformation
- DAX for calculated fields and KPIs
- Slicers and dynamic filtering

---



## 🚀 How to Use
1. Clone or download the repository.
2. Open the `.pbix` file in Power BI Desktop.
3. Load your own dataset or use the sample provided.
4. Use slicers (Date, Channel, City) to explore and interact with the data.
5. Gain insights to drive operational improvements.
